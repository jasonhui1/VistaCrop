## 2025-04-11 - Accessible Sidebar Toggles
**Learning:** Icon-only sidebar toggle buttons in this application lacked standard accessibility patterns. For these types of interactive elements, it is crucial to provide a descriptive `aria-label`, manage the toggle state using `aria-expanded`, hide visually redundant child SVGs using `aria-hidden="true"`, and ensure they have prominent keyboard focus rings.
**Action:** When creating or modifying icon-only toggle buttons (like sidebars or menus), always include `aria-label`, `aria-expanded` state, `aria-hidden="true"` on inner SVGs, and clear `focus-visible` ring utilities (e.g., `focus-visible:ring-2 focus-visible:outline-none focus-visible:ring-[var(--accent-primary)]`) to maintain visual consistency with the design system.
