## 2024-04-08 - Added accessibility states to interactive elements
**Learning:** Found several interactive UI components lacking standard accessibility states. Specifically, many toggles and buttons use only visual changes (like text color or border) or rotation (on icons) to convey state, which is invisible to screen readers. Focus rings on buttons aren't consistently styled using the app's accent variables, and many icon-only buttons lack both `aria-label` and `aria-expanded`/`aria-pressed` attributes.
**Action:** Always verify that state changes are communicated via ARIA attributes (e.g., `aria-expanded`, `aria-pressed`, `aria-current`) rather than just relying on CSS classes. Ensure all icon-only buttons include an `aria-label` and visual `focus-visible` states mapping to the design system (e.g., `focus-visible:ring-2 focus-visible:ring-[var(--accent-primary)] outline-none`). When a UI element hides/shows content (like the sidebars), use `aria-expanded`.
