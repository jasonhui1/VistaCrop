## 2024-04-26 - High-Frequency Event State Anti-Patterns
**Learning:** In React components managing canvas interactions (like `FreeformCanvas.jsx`), placing O(N) array lookups (e.g., `find()`) inside continuously firing event handlers like `mousemove` causes significant performance degradation. Additionally, updating incremental state via continuous React state setters (e.g., `setDragState`) within these handlers triggers excessive component re-renders.
**Action:** When handling high-frequency drag events, cache initial lookup data into the drag state object during the `mousedown` initialization phase. Calculate continuously updating values (like absolute custom points during corner dragging) as deltas from this initial state without issuing continuous intermediate state updates that force full re-renders. Ensure the modified handler no longer relies on the full arrays by removing them from its dependency array.
