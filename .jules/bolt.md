## 2025-01-26 - O(N) Array Lookup Optimization in Drag Handlers
**Learning:** During high-frequency events like `handleMouseMove`, performing O(N) array lookups (e.g., `crops.find()` or `placedItems.find()`) on every frame degrades performance and forces unnecessary dependencies on large arrays. Additionally, calculating relative deltas to a continuously updating `dragState` requires constant React state setter calls (`setDragState`) that trigger full component re-renders.
**Action:** Pre-cache O(N) lookup results (like `startCrop` and `startItem`) into the initial `dragState` object during the `mousedown` event. Use these cached objects in the move handler, and remove the arrays from the `useCallback` dependency array. For dynamic values like polygon `customPoints`, calculate absolute deltas from the initial `startItem` state rather than continuous relative deltas, completely eliminating the need to update `dragState` during the move.
