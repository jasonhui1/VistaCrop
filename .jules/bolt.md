## 2024-04-09 - Precomputing O(1) Arrays into Drag State
**Learning:** In the `FreeformCanvas` component, the `handleMouseMove` event fired continuously during high-frequency dragging. Originally, it repeatedly executed multiple O(N) array scans (`crops.find` and `placedItems.find`) on every single mouse movement, which created an unnecessary performance bottleneck (O(N*M)) in the React render cycle since state and props can grow as items are added to the canvas.
**Action:** By lifting these array lookups into the `handleItemMouseDown` initialization phase and caching the found `crop` and the relevant `item` directly into the `dragState` object, we eliminated the O(N) lookups completely from the high-frequency `handleMouseMove` handler without resorting to using `useMemo` to construct full Maps (which was highlighted as a performance anti-pattern in the project boundaries).
