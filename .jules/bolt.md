## 2024-04-30 - Optimize High-Frequency Drag Events\n**Learning:** In high-frequency drag events (`handleMouseMove`), continuous O(N) array lookups (like `crops.find`) and continuous React state setter calls (`setDragState`) that only update incremental UI coordinates cause severe performance bottlenecks and full component re-renders on every frame.\n**Action:** Cache O(N) array lookups into the `dragState` object during the initialization event (e.g., `mousedown`). Calculate incrementally changing values (like polygon custom points) as absolute deltas from the initial `startItem` state rather than updating them relative to the current state, and remove the continuous `setDragState` call.
