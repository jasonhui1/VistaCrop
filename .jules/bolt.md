## 2025-04-25 - Freeform Drag Performance Optimization\n**Learning:** High-frequency drag events (e.g., handleMouseMove) trigger performance bottlenecks when they perform O(N) array lookups (like crops.find) on every frame. Additionally, incrementally updating state and continuously triggering React setters during drag events causes unnecessary full-component re-renders.\n**Action:** Cache O(N) lookups into the initial dragState object during the initialization event (mousedown). Calculate continuous variables (like custom polygon points) as absolute deltas from the initial start state rather than updating them incrementally relative to current state. Remove the source arrays (crops, placedItems) from the high-frequency handler's useCallback dependency array to prevent recreation.
