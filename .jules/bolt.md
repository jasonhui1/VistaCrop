## 2024-05-18 - Caching lookups and avoiding state setters for high-frequency events
**Learning:** During high-frequency events like drag-and-drop (`handleMouseMove`), continuous array lookups (`Array.prototype.find`) and continuous React state updates using the previous state (`setDragState(prev => ...)`) severely degrade performance. We learned that `placedItems` and `crops` are passed by reference and should be accessed from a cached state inside the initializing interaction (`handleItemMouseDown`) rather than continuously finding them.
**Action:** Always precalculate and cache the required references inside the starting event handler (like `mousedown`), use them within the high-frequency event (like `mousemove`), compute absolute deltas from the initial state instead of incrementally updating state, and eliminate the source arrays from the dependency list of `useCallback`.
