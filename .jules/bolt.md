## 2025-04-04 - Caching Arrays in DragState for O(1) Lookups in React
**Learning:** High-frequency events like `handleMouseMove` can cause significant performance bottlenecks if they contain O(N) array lookups (e.g., `Array.find()`) inside the handler. Doing this in heavily rendered components degrades performance and causes stutter during interactions. Attempting to fix this by using `useMemo` to precompute standard Maps out of frequently changing arrays (like `placedItems` or `crops`) is a performance anti-pattern, because the Map is rebuilt on every state change, causing unneeded re-renders.
**Action:** The ideal solution for high-frequency drag events is to cache O(N) array lookups directly into the temporary `dragState` object during the initialization event (e.g., `mousedown`). This provides `O(1)` access during `mousemove` without incurring any re-render or rebuilding costs for the global arrays. Ensure that dependencies are carefully updated in `useCallback` when using this approach to avoid stale closures.
