## 2024-05-15 - Caching O(N) Array Lookups in High-Frequency Drag Events
**Learning:** During high-frequency events (e.g., `handleMouseMove` for dragging/resizing), performing O(N) array lookups like `crops.find` or `placedItems.find` on every frame causes unnecessary CPU overhead. Furthermore, if these arrays are included in the `useCallback` dependency array of the high-frequency handler, any unrelated state update to those arrays might trigger a re-render or re-creation of the callback.
**Action:** Cache the necessary references (e.g., `startCrop`, `startItem`) inside the `dragState` object during the initialization event (e.g., `mousedown`). In the high-frequency handler, use the cached objects and calculate absolute deltas from the initial state, rather than fetching the current state. This allows removing the source arrays from the dependency array.
