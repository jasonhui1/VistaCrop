## 2026-04-05 - Drag Initialization Optimization\n**Learning:** High-frequency event handlers like 'mousemove' in canvas interactions create extreme bottlenecks if O(N) operations like Array.find() are evaluated inside them. Finding the object to interact with only happens once when the user begins the interaction on 'mousedown'.\n**Action:** Always extract O(N) searches out of high-frequency render or event loops, by caching references directly in the state tracking the active interaction (e.g. attaching 'crop' directly to 'dragState'). Ensure dependency arrays are updated properly to prevent stale closures.
