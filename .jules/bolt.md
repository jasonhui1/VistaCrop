## 2025-04-18 - Performance optimization on FreeformCanvas
**Learning:** During high-frequency drag events, calculating incrementally changing values (like polygon custom points) as absolute deltas from the initial state rather than updating them relative to the current state avoids continuous React state setter calls that trigger full component re-renders. Also, converting frequently changing arrays to Maps inside a component body via useMemo degrades performance, but caching O(N) array lookups into the dragState object during the initialization event (mousedown) removes the need for O(N) lookups inside the high-frequency handler.
**Action:** When optimizing high-frequency events, look to avoid continuous state updates, and cache expensive lookups into the event's start state.
