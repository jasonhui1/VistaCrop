## 2024-05-18 - Absolute Deltas for High-Frequency Events
**Learning:** During high-frequency drag events (like `onMouseMove`), fetching the latest component state (via `O(N)` lookups like `Array.find`) or performing continuous incremental React state updates (e.g., calling `setDragState` repeatedly) causes significant performance bottlenecks by triggering full component re-renders.
**Action:** Always cache initial lookup data (like `startCrop`, `startItem`) into the interaction state object during initialization (e.g., `onMouseDown`). Then, during high-frequency handlers, calculate values incrementally as absolute deltas relative to this initial state. This allows eliminating source arrays from `useCallback` dependency arrays to prevent handler recreation and avoids excessive component updates.
