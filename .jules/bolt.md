## 2024-05-24 - Optimizing Hot Path Array Lookups in Canvas Interactions
**Learning:** In highly interactive components like `FreeformCanvas`, executing `Array.prototype.find()` operations within `handleMouseMove` (which fires hundreds of times per second during a drag operation) creates a noticeable `O(N)` CPU bottleneck. This is compounded when the same lookup is used within the render cycle of child components.
**Action:** When working with canvas loops, dragging logic, or large repeating data structures, always wrap the base array in an `O(1)` `Map` using `useMemo` (e.g., `cropsMap`). Look up items by ID (`cropsMap.get(id)`) instead of searching (`crops.find(c => c.id === id)`). For static global constants (like `FILTERS`), precompute the `Map` entirely outside the React component to avoid any memory reallocation.
