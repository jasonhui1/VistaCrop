## 2024-05-24 - Accessible Icon-Only Toggles
**Learning:** Icon-only sidebar toggles need explicit ARIA labels, `aria-expanded` state tracking, and hidden SVGs (`aria-hidden="true"`) to be screen reader friendly, along with clear focus visible styles (`focus-visible:ring-2 focus-visible:outline-none`) for keyboard navigation.
**Action:** Always add ARIA and focus styles to icon-only buttons when making UX improvements.
