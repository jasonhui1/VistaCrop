## 2024-05-10 - Restoring Keyboard Focus Outlines on Custom Buttons
**Learning:** The project's custom CSS reset in `src/index.css` strips default focus outlines from `<button>` elements (e.g., `button { border: none; outline: none; }` equivalent). This completely breaks keyboard accessibility by removing the browser's default focus indicator.
**Action:** When adding or updating interactive elements, always explicitly apply Tailwind `focus-visible` utility classes inline (e.g., `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-[var(--accent-primary)]`) to restore the visual focus ring for keyboard users, ensuring compliance with accessibility standards. For tightly packed items like flex layouts, include `relative focus-visible:z-10` to prevent the focus ring from being clipped.
