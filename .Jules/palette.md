## 2025-05-07 - Add explicit focus indicators for button elements
**Learning:** The custom CSS reset in `src/index.css` completely strips default focus outlines from `<button>` elements. Because of this, it is necessary to explicitly add Tailwind focus utility classes (such as `focus-visible:ring-2`) to interactive elements. Furthermore, tight flex layouts can clip the focus rings, requiring the addition of `relative z-10` or a similar solution to make the focus ring visible on active items.
**Action:** When creating or modifying button elements or custom interactable controls in this project, always check if they have focus styling defined via Tailwind classes. Add explicit `focus-visible` ring styling to maintain accessibility, and remember to handle z-index context issues for clipped rings.
